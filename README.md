# Student Grade Calculator

A simple, responsive web application that calculates a student's grade based on their marks and provides performance feedback.

## Features

- Accepts student marks between 0 and 100.
- Automatically calculates the corresponding grade.
- Displays performance feedback.
- Validates empty and invalid inputs.
- Provides a clean, dark-themed interface.
- Responsive design for mobile, tablet, and desktop screens.

## Grading System

| Marks | Grade | Performance |
|---|---|---|
| 80–100 | A | Outstanding |
| 70–79 | B | Above Average |
| 60–69 | C | Average |
| 50–59 | D | Below Average |
| 0–49 | F | Poor |

## Technologies Used

- HTML5 – Page structure
- CSS3 – Styling and responsive design
- JavaScript – Grade calculation, validation, and DOM manipulation

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your marks and click **Calculate**.
